## Deskripsi

Aplikasi ini dibuat untuk memenuhi tugas praktikum Pemrograman Aplikasi Mobile dengan menggunakan Kotlin dan Jetpack Compose. Aplikasi menyediakan formulir pengisian biodata yang memungkinkan pengguna memasukkan data diri, memilih tanggal lahir melalui kalender, serta menentukan pengalaman dan keterampilan yang dimiliki.

Setelah formulir diisi dan tombol **Proceed** ditekan, aplikasi menampilkan hasil pendaftaran beserta validasi data yang telah dimasukkan.

## Fitur Aplikasi

- Formulir input nama depan dan nama belakang.
- Input alamat email.
- Pemilihan tanggal lahir menggunakan kalender.
- Pemilihan pengalaman melalui pilihan yang tersedia.
- Pemilihan keterampilan menggunakan checkbox.
- Validasi dan penampilan hasil input setelah tombol Proceed ditekan.
- Tampilan antarmuka menggunakan Jetpack Compose.

## Teknologi yang Digunakan

- **Bahasa pemrograman:** Kotlin
- **Framework UI:** Jetpack Compose
- **IDE:** Android Studio
- **Komponen UI:** Material 3
